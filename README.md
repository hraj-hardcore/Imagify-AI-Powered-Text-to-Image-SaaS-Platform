# Imagify — AI-Powered Text-to-Image SaaS

Imagify is a full-stack AI-powered SaaS application that transforms text prompts into images using the **Clipdrop API**. Built with the **MERN stack**, it provides a complete user ecosystem with secure authentication, credit-based image generation, and online payments.

### Key Features

* 🤖 **AI Image Generation** — Generate images from text prompts using the Clipdrop API.
* 🔐 **Authentication** — Secure user registration and login using JWT and bcrypt.
* 💳 **Credit System** — Users receive credits for image generation, with automatic deduction after successful generation.
* 💰 **Razorpay Integration** — Purchase credits through secure online payments with payment verification.
* 🗄️ **MongoDB Database** — Stores user profiles, credit balances, and transaction history.
* 🎨 **Responsive UI** — Modern interface built with React and Tailwind CSS, including landing, pricing, generation, and result pages.
* ⚡ **REST API** — Node.js and Express.js backend with modular controllers for authentication, image generation, and transactions.

### Tech Stack

**Frontend:** React.js, Tailwind CSS
**Backend:** Node.js, Express.js
**Database:** MongoDB, Mongoose
**Authentication:** JWT, bcrypt
**APIs:** Clipdrop API, Razorpay
